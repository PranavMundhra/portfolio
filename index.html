Grading severity from retinal images

Results 78.54% test accuracy, 67.85% balanced accuracy and Cohen’s kappa of 0.680. Team project; the code is on a teammate’s repository.

In progress

RUL-Prediction-PVDAQ

Trust the data before the model

A data-preparation and forecasting project on NREL’s PVDAQ System 50 solar data. A pipeline that keeps every measurement and audits every decision has turned about 5.8 million raw readings from 8,455 files into clean hourly and daily series.

How it works Repeated readings are de-duplicated, conflicting ones are set to missing rather than averaged, and nothing is interpolated or deleted. Every run records its settings, source hashes and status.

Status In progress: the pipeline has run end to end on the real data, and forecasting experiments comparing simple baselines, ARIMA and Auto ARIMA are under way. The remaining-useful-life model comes later.

Python / Time series / ARIMA / Parquet
