Emotion-Based Anime Recommender

A conversation before a recommendation

A Streamlit companion that talks with you about how you feel and finds anime for the experience you want, with no forms or genre picks required. It searches the public AniList catalogue, ranks candidates by sentence-embedding similarity (falling back to word overlap), strictly enforces exclusions and watched titles, and explains each pick with one validated Gemini or Mistral call.

Status V2 is on GitHub with 79 tests passing in CI. On a hand-made test set it cut hard-constraint violations from 20 to 0; testing with live model output and real users is still to come.
