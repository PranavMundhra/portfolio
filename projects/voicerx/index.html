Team project · Healthcare AI

VoiceRX

Doctor talks, notes write themselves: speech in, structured clinical documentation out.

My contribution

I built the entire user interface: the Streamlit web app that patients and doctors use to record a consultation and read the generated note and prescription.

How the platform works

The team's pipeline transcribes the consultation, maps symptoms to SNOMED CT codes through a Neo4j graph, and uses GPT-4o to draft a structured note and prescription. The interface serves both a patient view and a doctor view.

Stack: Python, Streamlit, Whisper, noisereduce, Neo4j, SNOMED CT, and Azure OpenAI GPT-4o.
