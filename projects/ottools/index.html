OTTools

A coauthored optimization toolkit with an interactive interface for exploring solutions.

Purpose and methods

OTTools addresses linear-programming and transportation problems through a Python package and a Streamlit interface. The package documents Simplex, Big-M, Vogel's Approximation, Least Cost, and MODI methods. Version 0.1.2 has been on PyPI since April 2025.

Attribution

PyPI lists Pranav Mundhra and Mohammad Saad Nathani as authors. I co-authored the package and built its Streamlit interface, and the application repository credits me with the frontend.
