OTTools

A PyPI package for linear-programming and transportation problems, and a website that shows each method working step by step.

Purpose and methods

OTTools is a Python package for linear-programming and transportation problems. For linear programming it offers the graphical method (two or three variables), Simplex, Big M for mixed constraints, and integer programming by branch and bound. For transportation it offers the North-West Corner rule, Least Cost, Vogel's Approximation, and MODI. The first release went to PyPI in April 2025, and version 0.1.3 followed on 6 November 2026 after a round of bug fixes.

The Streamlit website

The website shows the package working. On the Linear Programming and Transportation pages you enter a problem in an editable table or load an example, pick a method, and see the answer in three tabs: the result, a chart (linear programming) or a flow (transportation), and the exact OTTools call that produced it. Every result is computed live by the package; nothing is hard-coded.

A Learn page walks through all eight algorithms on worked examples. The package returns only final answers, so the lessons use small teaching versions of each algorithm that record every intermediate step. Each lesson also runs the real package on the same problem and shows whether the two answers match.

Building on version 0.1.3 meant working around two limits of the graphical method. It only maximises with less-than-or-equal constraints, so the site converts minimise problems and greater-than-or-equal and equality rows before the call, and says so on the page. It also opens its own Plotly figure, which the site captures and draws on the page. The site double-checks each graphical answer with Big M, so an unbounded problem is not reported as optimal.

Attribution

I co-authored OTTools with Mohammad Saad Nathani. Saad was responsible for the linear-programming part of the package and I was responsible for the transportation part. I also built the Streamlit website on top of it that demonstrates via an example how this package can be used in real-world application.

Current boundaries

The website has no automated test suite yet. During development, every page, example, and method was exercised with Streamlit's AppTest, and all eight lessons were checked against version 0.1.3.

Planned next:

  • Step-by-step output from the package itself, such as tableaux and MODI values, in place of the teaching versions.
  • Running several methods on one problem side by side.
  • Exporting results to CSV or LaTeX.
  • Sensitivity analysis.
