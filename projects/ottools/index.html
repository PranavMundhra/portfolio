Optimization · Python package

OTTools

A coauthored optimization toolkit with an interactive interface for exploring solutions.

Purpose and methods

OTTools addresses linear-programming and transportation problems through a Python package and a Streamlit interface. The package documents Simplex, Big-M, Vogel's Approximation, Least Cost, and MODI methods.

Attribution

PyPI lists Pranav Mundhra and Mohammad Saad Nathani as authors. The application repository identifies me with frontend development and links a separate library repository.

Specific algorithm, visualization, packaging, and release responsibilities are not yet documented here.

Evidence and validation boundaries

The package and both source repositories provide public evidence of the work. A worked example, correctness tests, and supported edge cases are not included in this overview.
